نتيجة تنفيذ التحويل المحلي إلى Phoenix LiveView

النتيجة

  • تطبيق Elixir/Phoenix LiveView يعمل محليًا ويخدم الواجهة وطلبات المعالجة، مع محرك Python مستمر معزول يحافظ على وظائف PDF الحالية.
  • تأكد اتصال LiveView الحقيقي وبدء hook وحفظ العربية/الإنجليزية والمظهرين. تبقى التفاعلات الرسومية في JavaScript داخل hook؛ لم تُعد كتابة محرك PDF بلغة Elixir.

التوصية

  • استكمال تحقق الرفع/التنزيل من المتصفح وتهيئة مشغّل الحزمة وWebSocket في staging قبل طلب النشر. لا يكفي نجاح الاختبارات المحلية لوصف الموقع المنشور بأنه تحول.

ما تغير

  • أضيف تطبيق web/ بعقد تبعيات mix.lock، وواجهة LiveView وhooks والأصول العامة.
  • أضيف عامل PDF بلا منفذ HTTP ثانٍ، ونقل ملفات على القرص بدل رسائل تضم المستند كاملاً. طابور محدود، ومهلة وفشل واضح دون تكرار المهمة تلقائيًا.
  • جلسات المعاينة مرتبطة بمساحة العمل الموقعة، وحالة المهمة الأخيرة محفوظة مؤقتًا خارج اتصال المتصفح.
  • أضيف فحص CI خاص بـLiveView وبرامج قبول وقياس وحزمة محلية ذات manifest وبصمات. لم تُشغّل CI على GitHub ولم يحدث push.
  • الملفات الثابتة الأصلية ومحركات الحساب وإعدادات اللغة والمظهر وOCR والحدود بقيت مصدر الواجهة والمعالجة.

عيوب كشفتها الفحوص وأُصلحت

  • حماية نماذج المتصفح كانت تمنع تحميل JavaScript العام؛ فُصل مسار الأصول العامة عن حماية النماذج مع بقاء حماية الصفحة وعمليات المعالجة.
  • رفض المهام الزائدة كان يرد باستخدام حالة HTTP سابقة لقراءة الجسم، ما عطّل اتصالات keep-alive. أُصلح ثم نجح اختبار الضغط وإعادة استخدام الاتصال.
  • تحديث حالة المهمة لم يعد يعيد توليد محتوى المحرر كاملاً في كل تحديث.
  • حزمة BEAM تعمل دون شبكة Erlang موزعة، وتستبعد ملفات COOKIE، ولا تحمل أسرار إنتاج.

حدود وبوابات متبقية

  • رفع الملفات في IAB أعطى Failed to fetch قبل وصول الطلب إلى الخادم. Chrome رفض الرفع الآلي بسبب صلاحية إضافة غير مفعلة. لم تُغيّر الصلاحيات ولم يُتجاوز الحظر. تنزيل HTTP وPDF الناتج اختُبرا بنجاح، لكن مسار المتصفح نفسه ما زال غير مؤكد.
  • لا توجد مجموعة مستندات عربية واقعية أو تقييم شامل للكتابة اليدوية؛ نتيجة العينة الاصطناعية لا تعمم.
  • العمال عامل واحد تسلسلي بطابور محدود، وليست هذه النسخة pool متعدد العمال أو سجل مهام دائمًا. فقد العامل يعيد إنشاء جلسات المعاينة وفق سلوك المتصفح السابق؛ لا استئناف حساب مجهول أو إعادة تلقائية.
  • مسار Project Manager الحالي مهيأ لـwheel وواجهة Python القديمة. يلزم تكامل لحزمة LiveView وفحص HTTP/WebSocket والجلسات والتحويل والعودة في staging. مصدر المدير خارج نطاق كتابة هذه المهمة، ولم يُعدّل.
  • لا نشر أو commit أو push أو رسائل. النسخة العامة بقيت دون تغيير. طلب تنفيذ المهام لا يجعل الحزمة المعرفة تفويضًا للنشر أو تعديل الصلاحيات.
